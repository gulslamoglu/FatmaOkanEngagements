# Çift fotoğrafları

Yalnızca Fatma ve Okan için seçtiğiniz fotoğrafları bu klasöre koyun.

- JPG, JPEG, PNG, WebP veya AVIF; en fazla 6 fotoğraf.
- Sıralama için 01.webp, 02.webp, 03.webp gibi adlar kullanabilirsiniz.
- Telefonlarda hızlı açılması için yaklaşık 1920 piksel genişlik ve fotoğraf başına 300–600 KB önerilir.
- Dosyaları ekledikten sonra npm run dev komutunu yeniden başlatın. Yayında npm run build sırasında liste otomatik oluşturulur.
- Fotoğraflar Supabase'e yüklenmez; site dosyalarıyla sunulur ve herkes tarafından erişilebilir.
- Klasör boşsa mevcut kapak gösterilir. Misafir galerisi bu alana otomatik alınmaz.
